Command language created for more elegant and intuitive automation.

WARNING

This project is not currently being worked on, and it has not reached a usable stage.

Reason: I want to focus on other things right now. The specification should be useful for anyone willing to work on the project!

I enjoy the idea of scripts — I use it all the time for project build pipelines and utilities; improve the DX on my system, etc.

However a big issue to me is that both Makefile and Bash have done questionable syntax design decisions making it annoying to write.

The goal of Tomefile is to make scripting more simple and predictable, with tools like LSPs to assist without requiring the user to look things up on the internet.
