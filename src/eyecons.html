A 16x16 stylized vector icon pack that aims to be consistent & pixel-perfect.

I didn't enjoy any of the existing icon packs as they either look ugly or inconsistent. Creating this project let me learn why that is the case — consistent 16x16 icons are incredibly difficult to make.

This project was started by RuMaks.
